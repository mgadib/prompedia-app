# Prompt Notes

Catatan pribadi untuk prompt.

## Fitur

* Login sederhana (email + password)
* Paste prompt → simpan dengan 1 klik
* Tambah tag (opsional)
* Lihat semua prompt dengan filter real-time
* Klik prompt untuk edit

## Tech Stack

* React + TypeScript
* Vite
* Tailwind CSS
* Supabase (auth & database)

## Development

```bash
npm install
npm run dev
```

Buka `http://localhost:8080`

## Build

```bash
npm run build
```
